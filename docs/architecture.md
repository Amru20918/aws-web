\# AWS Timer Web Application



\## Project Overview

A timer web application deployed on an Ubuntu EC2 instance using Nginx.



\## Architecture

User Browser → Internet → EC2 Public IP → Nginx → Timer Application



\## AWS Services

\- Amazon VPC

\- Amazon EC2

\- EC2 Security Groups

\- Amazon EBS storage



\## Technologies

\- Ubuntu Linux

\- Nginx

\- HTML, CSS and JavaScript

\- Git and GitHub



\## Security

\- Restrict SSH access to a trusted IP address.

\- Do not upload private keys or AWS credentials to GitHub.

\- HTTP was used for this learning project.



\## Cost Management

The EC2 instance is stopped when not required. Storage and other resources may still incur charges.
