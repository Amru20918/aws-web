\# Amruta Timer - AWS Project



A timer web application hosted on AWS EC2 using Nginx.



\## Features

\- Start

\- Stop

\- Set countdown time

\- Reset



\## Technologies

\- AWS EC2

\- Ubuntu Linux

\- Nginx

\- HTML, CSS, JavaScript

\- Git and GitHub



\## Deployment

The application is hosted on an Ubuntu EC2 instance.

Nginx is used as the web server.



\## Security

The EC2 private key is not included in this repository.
